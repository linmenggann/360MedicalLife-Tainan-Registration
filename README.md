# 360°醫學人生｜走進臺南，走進生活 — 活動報名網頁

奇美醫院教學部「360°醫學人生｜走進臺南，走進生活」二日走讀活動的線上報名網頁。
單一 `index.html`，響應式設計，含臺南府城街巷、市場、廟宇、稻田、四草綠色隧道等動態視覺元素。

## 啟用即時名額（連接 Google 試算表）

1. 建立一個 Google 試算表，開啟「擴充功能 → Apps Script」，貼上 `apps-script/Code.gs` 的內容。
2. 「部署 → 新增部署作業 → 網頁應用程式」，執行身分「我」、存取權「所有人」。
3. 複製網頁應用程式網址，填入 `index.html` 內的 `CONFIG.API_URL`。
4. 網頁每 30 秒自動更新各身分剩餘名額；送出報名時後端會再次檢查名額與重複人事號。

`API_URL` 留空時為示範模式，名額計數僅存於瀏覽器的 localStorage。

## 部署至 GitHub Pages

Settings → Pages → Source 選 `main` 分支根目錄即可。
